# **App Name**: DIBF Global Impact

## Core Features:

- Initiatives Dashboard: Dynamic display for Tinewonsa Project, Dollar-A-Day Campaign, and the African Field School using rounded, premium UI cards.
- AI Partnership Proposal Assistant: An AI-powered tool that helps potential partners generate customized collaboration proposals based on DIBF’s core focus areas.
- Global News & Insights Engine: A database-driven publication hub for sharing impact stories, outreach reports, and research papers from the community.
- Integrated Volunteer & Inquiry System: Cloud-synced contact management to handle volunteer applications and corporate CSR partnership requests seamlessly.
- Campaign Support Module: A dedicated giving portal allowing users to explore different support paths including direct donations and institutional backing.
- Focus Area Exploration Tool: Interactive UI grid for exploring focus areas like Youth Leadership, Mental Health, and Sustainable Development with quick-link CTAs.

## Style Guidelines:

- Primary color: Medical Blue (#0F6CBD) representing health equity and professional credibility.
- Background color: Soft Sky (#F2F6F9) – a clean, light blue tinted white for a modern, humanitarian feel.
- Accent color: Vibrant Teal (#17A19A) for energetic call-to-action buttons and highlighted initiative cards, matching the brand request.
- A font pairing featuring 'Inter' for clean, machine-precise headlines and 'PT Sans' for warm, readable body text across diverse screen sizes.
- Outline-style icons with soft-rounded edges for health, community, and education categories, ensuring a premium agency-grade look.
- Mobile-first, masonry-style grids for impact stories and soft-shadow rounded containers to differentiate foundation initiatives.
- Smooth fade-in-up entrance transitions for core mission statements and gentle scaling hover effects on primary 'Give' and 'Partner' actions.
